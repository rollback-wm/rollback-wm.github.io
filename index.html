Core idea

Going back in a world model

Most world‑model‑based methods only run the world model forward, just like the real world. A world model can also go back. Rollback returns to earlier decision points of real and simulated attempts, tries other actions from there, and compares how they end. The comparison tells which actions were better, without training a value model. Real‑world data is used along the way to keep correcting the world model.

Method

How Rollback works

The world model, GE‑Sim 2.0, predicts the three camera views and the robot's joint states, so the policy gets the same kind of input in simulation as in the real world.

01

Experience‑backtracking search

Starting from real trajectories, the search restores saved world‑model states and tries other action chunks. MCTS spends more of the budget on decisions where different actions lead to different outcomes.

02

Tree‑structured value estimation

Sibling branches start from the same state, so comparing their outcomes shows how good each action is. These comparisons become action‑level labels; no value model is trained.

03

World model–policy co‑evolution

The robot keeps collecting data while the policy trains. The new data is used to fine‑tune the world model, so later searches run on a more accurate simulator.
